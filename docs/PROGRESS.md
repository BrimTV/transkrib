## Обещания в ЧИТАЙ.txt, которые надо закрыть до релиза

пункта ещё не реализованы, релиз без них выпускать нельзя:

  готов, но не подключён к `main()`; подключение за оркестратором;

- кнопка «Открыть лог» сейчас есть только на экране ошибки запуска, в настройках её нет.

## Правило владения файлами

В один момент времени файл принадлежит одному исполнителю. Оркестратор раздаёт владение
в задании. Горячие файлы: `app/engine.py`, `app/main.py`, `app/ui/index.html`.
