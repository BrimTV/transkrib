## Найдено и починено 03.09.2026 (после закрытия ТЗ)

Каждая строка — то, что нашлось не по плану, а при попытке отдать сборку людям.

| Что | Чем грозило | Как поймали |
|---|---|---|
| Окно лежало в объекте-мосте под открытым именем | pywebview перед стартом обходит мост рекурсивно; на Windows обход уходил в дерево .NET WebView2 — тысячи ошибок COM, предел рекурсии, процесс не закрывался | проверка окна в CI висела 6 часов |
| Ни одного `timeout-minutes` в CI | зависший шаг выбрал лимит оплаты минут Actions, сборки встали | тот же случай |
| Список путей перетаскивания не чистится библиотекой | запасное сопоставление могло подставить файл из прошлого перетаскивания | чтение исходников pywebview |
| Кириллица в имени приходит в разных формах записи | путь к файлу терялся, перетаскивание «не работало» | лог владельца |
| В macOS-архиве не было инструкции | неподписанное приложение система не открывает, а совет из README с macOS 15 не работает | ручная проверка перед раздачей |
| Проверка каналов декодировала весь файл | лишняя минута и гигабайты памяти на каждом стереофайле | ревизия своей же работы |
| Перетащенная папка давала ошибку | обычный способ «закинуть записи» не работал | здравый смысл |
| В тесте путь резался по прямой косой черте | тест падал только на Windows | CI |
| Выкладка релиза скачивала архивы и следом их затирала | релиз по тегу вышел бы с описанием и нулём файлов при зелёном CI | ревизия |
| Часть перетащенных файлов пропадала при смешанных именах | восстановление пути было «всё или ничего» | ревизия |
| Эхо второго канала принималось за собеседника | человеку утвердительно сообщалось, что стало точнее | ревизия |
| Окно отдавало страницу из системного кеша | после обновления программы — старый интерфейс поверх нового движка | новая проверка интерфейса в `--smoke` |

## Правило владения файлами

В один момент времени файл принадлежит одному исполнителю. Оркестратор раздаёт владение
в задании. Горячие файлы: `app/engine.py`, `app/main.py`, `app/ui/index.html`.
