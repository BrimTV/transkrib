ЧИТАЙ.txt — Transkrib для Windows
==================================

Что это
-------
Transkrib — программа для расшифровки аудио и видео в текст. Работает целиком на
вашем компьютере, ничего не отправляет в интернет и не требует регистрации.
Перетащите файл в окно (или выберите его кнопкой) — рядом появятся текстовые
файлы (.txt и .srt с субтитрами). Есть также конвертер форматов и разделение
текста по говорящим.

Есть два варианта поставки:
  - lite   — модель полегче, считает на процессоре. Подходит для любого компьютера.
  - medium — модель точнее, на компьютере с видеокартой NVIDIA считает на ней
             и заметно быстрее; без такой видеокарты тоже работает, но медленнее
             (переходит на процессор автоматически).
Какой у вас архив — видно по имени: Transkrib-lite-windows.zip или
Transkrib-medium-windows.zip.

Если у вас видеокарта NVIDIA, скачайте рядом ещё один файл —
Transkrib-medium-windows-nvidia.zip — и распакуйте его в ту же папку, куда
распаковали программу, ответив «Да» на вопрос об объединении папок. Без него
программа считает на процессоре: медленнее, но работает.

Системные требования
---------------------
  - Windows 10 версии 1903 или новее, либо Windows 11. Только 64-разрядная
    (x64). Windows 7 и 8.1 не поддерживаются.
  - Память: от 4 ГБ для lite, от 6-8 ГБ для medium.
  - Место на диске: 2-3 ГБ (программа с уже встроенной моделью).
  - Компонент Microsoft WebView2 — на современной Windows 10/11 он почти всегда
    уже установлен вместе с обновлениями. Если его не окажется, Transkrib сам
    об этом скажет при запуске и предложит скачать.

Установка
---------
1. Скачанный архив (.zip) сначала правой кнопкой мыши -> "Свойства" -> внизу,
   если есть, поставить галочку "Разблокировать" -> ОК. Так Windows перестанет
   считать файлы внутри "скачанными из интернета" — без этого шага программа на
   некоторых компьютерах не запускается вовсе (тихо закрывается или пишет про
   Python DLL).
2. Распаковать архив ЦЕЛИКОМ: правой кнопкой по архиву -> "Извлечь всё..." и
   выбрать папку. Открывать программу прямо из окна архива (двойным кликом,
   не распаковывая) нельзя — она не запустится ("Failed to load Python DLL").
3. Папку с программой лучше держать поближе к корню диска, например
   C:\Transkrib, и не класть её в папку OneDrive (там файлы синхронизируются и
   программе бывает сложно с ними работать). Длинный путь с множеством
   вложенных папок тоже может помешать запуску.
4. Запускать файл Transkrib\Transkrib.exe.

Первый запуск занимает 10-20 секунд — это нормально, дальше окно открывается
быстрее.

"Windows защитила ваш компьютер" (SmartScreen)
------------------------------------------------
Программа не подписана цифровой подписью (это платная услуга, и на неё пока не
пошли), поэтому при первом запуске Windows может показать синий экран
"Windows защитила ваш компьютер". Это стандартное предупреждение для любых
новых неподписанных программ, не признак проблемы. Нажмите "Подробнее", затем
"Выполнить в любом случае".

Антивирус
---------
Некоторые антивирусы могут ошибочно посчитать программу подозрительной — так
бывает с программами, собранными через PyInstaller (тем же способом собирают
множество Python-приложений). Если антивирус поместил файлы в карантин,
добавьте папку с программой в исключения антивируса и восстановите файлы.

Видеокарта NVIDIA (только для варианта medium)
-------------------------------------------------
Сначала распакуйте дополнение Transkrib-medium-windows-nvidia.zip в ту же папку
(см. выше) — без него библиотек для видеокарты в программе нет.

Для ускорения на видеокарте нужен драйвер NVIDIA версии 527 или новее. Если
драйвер старее или видеокарты NVIDIA нет, программа сама и без ошибок
переключится на процессор — просто расшифровка будет идти медленнее. Режим,
в котором сейчас работает программа, показан в шапке окна.

Если окно открылось пустым
-------------------------------
Закройте программу, удалите папку webview рядом с логом
(%LOCALAPPDATA%\Transkrib\webview) и запустите снова. Там лежат только
служебные данные встроенного браузера, ничего вашего.

Лог и обращение при проблеме
-------------------------------
Если что-то не работает как ожидалось, откройте лог-файл:
  %LOCALAPPDATA%\Transkrib\transkrib.log
(проще всего вставить этот путь в адресную строку Проводника). В настройках
программы также есть кнопка "Открыть лог". Пришлите этот файл вместе с
описанием, что вы делали и что пошло не так, — по нему проще всего понять
причину.

Где искать результат
----------------------
По умолчанию текстовые файлы (.txt, .srt) появляются рядом с исходным
аудио- или видеофайлом. Если туда нельзя записать (папка только для чтения,
сетевой диск), программа сообщит об этом и сохранит результат в папку
Документы\Transkrib — об этом тоже будет сказано на экране.
